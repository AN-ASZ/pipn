== Changes from Original

=== 1. Trigger: Focus → Minimize
The original extension triggers picture in picture when *focus leaves Firefox* (e.g. switching to another app).
This fork changes the trigger to *minimizing the Firefox window* instead.

=== 2. Download from this fork's Release page
[IMPORTANT]
====
If you want to try this modified version, download it from the link:../../releases[Releases page] of *this repository* — do **not** install from the original https://addons.mozilla.org/en-US/firefox/addon/pipn-auto-picture-in-picture/[Firefox Add-ons (AMO)] page, as that is the unmodified original extension.
====

== Getting Started
=== Installation
1. Go to the link:../../releases[Releases page] of this fork and download the latest `.xpi` file
2. In Firefox, open `about:addons`, click the gear icon, and select *Install Add-on From File*
3. Make sure `media.videocontrols.picture-in-picture.enable-when-switching-tabs.enabled` is set to `true` in `about:config`

=== Build from source
```
gh repo clone <your-username>/pipn .
cd pipn
npm install
make eb
make build
```

=== Using pipn
Once pipn is installed, on any browsing tab that has audio playing pipn will
attempt to enable picture in picture mode by *minimizing the Firefox window*.
Upon restoring the Firefox window, the newly created tab will be closed and you
will be returned to the original tab.

This differs from the original, which triggers on focus loss rather than minimize.

This workaround exists because Firefox does not support the https://bugzilla.mozilla.org/show_bug.cgi?id=1463402[Picture in
picture API].
